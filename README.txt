INTERACTIVE GUANOSINE-CAPPED FOUR-HELIX BUNDLE WITH HEME COFACTOR

Default view: Atomic detail (ball-and-stick)
Alternate view: Secondary structure (cartoon protein with atomic-detail guanosine cap and heme)

Connectivity fix:
The PDB contains explicit CONECT records for the molecular bonds so the browser viewer does not depend on incomplete bond inference for the custom GS2 and heme residues. It also includes the two axial Fe–His NE2 coordination links used in this model.

Local test:
1. Open Terminal.
2. cd ~/Downloads/guanosine_heme_bundle_viewer_connected
3. python3 -m http.server 8000
4. Open http://localhost:8000
